## P0 — Save/record freeze (root-caused, fix in flight)
Symptom: typing a text note and hitting Save freezes the app until killed;
record button dead afterward.
Root cause (device-proven): killed-process leftovers make the SAF backend
reattach to a native operation the supervisor no longer retains; the
`operationState` poll loop in `saf_storage_backend.dart` swallowed the
'unknown' PlatformException on the untyped path and slept 50 ms forever —
hot loop, pinned capture fence (`hasActiveCapture` true ⇒ every save/record
rejected busy), until Android killed the process (EXCESSIVE CPU USAGE),
recreating the same state next launch.
Fix: 'unknown' now settles the operation with a failure on BOTH typed and
untyped paths, releasing the fence. Regression test proven RED (30 s
timeout in loop) → GREEN.
Remaining: full gates, commit, rebuild, install, device-verify note save +
record + freeze non-recurrence.
