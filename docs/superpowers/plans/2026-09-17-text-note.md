# Text Note Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a third capture mode — Text Note — that saves typed notes into the existing Dumps collection with full list/search/selection/deletion/sync/durable-folder support.

**Architecture:** A text note is a `dumps` row with `mode='text_note'`, body in `transcript`, no audio (schema 5→6 relaxes `audioPath`/`audioSizeBytes` to nullable). Notes publish `<id>.md` + `<id>.meta.json` through the existing reservation→publish→commit pipeline (no recorder). Sync sends metadata-only (no audio upload). Server accepts the new mode and rejects transcription for it.

**Tech Stack:** Flutter/Dart (Drift, Riverpod), FastAPI/pydantic server, existing storage catalog/backend from the durable-transcription-recovery release.

**Spec:** `docs/superpowers/specs/2026-09-17-text-note-design.md` (committed at 37279eb). Base: main @ f8c0d80.
